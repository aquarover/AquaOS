# Purpose

This document defines the engineering principles followed by every member of Aqua Rover Technologies. These principles establish the mindset, responsibilities, and professional standards expected from all engineers contributing to AquaOS and the Aqua Rover project.

---

# Engineering Principles

## 1. Documentation First

If it is not documented, it does not exist.

---

## 2. Understand Before Building

Engineers must understand the problem before writing code or designing hardware.

---

## 3. Quality Over Speed

Deliver reliable, maintainable, and scalable solutions instead of quick fixes.

---

## 4. Learn Continuously

Every engineer is expected to continuously improve their technical and professional skills.

---

## 5. Build for the Team

Write code and documentation that others can easily understand and maintain.

---

## 6. Respect Version Control

Every meaningful change must be tracked through Git using descriptive commit messages.

---

## 7. Test Before Delivery

No feature is considered complete until it has been tested appropriately.

---

## 8. Continuous Improvement

Every iteration should improve quality, performance, maintainability, or usability.

---

# Engineering Mindset

Every engineer should strive to:

- Solve problems instead of assigning blame.
- Ask questions when uncertain.
- Share knowledge with teammates.
- Accept feedback professionally.
- Improve existing systems instead of creating unnecessary complexity.

---
# Core Engineering Values

Every engineer at Aqua Rover Technologies shall:

- Take ownership of their work.
- Prioritize safety, reliability, and sustainability.
- Communicate openly and respectfully.
- Continuously learn and improve.
- Contribute to the success of the team before individual recognition.
